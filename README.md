### `ABOUT`

Software Developer and Aspiring AI Engineer currently pursuing an undergraduate degree at IIT Kharagpur. Specializing in scalable web applications, real-time collaborative systems, and practical utility platforms. Currently pivoting towards cross-platform mobile app development and integrating NLP, LLMs, and AI-driven automation to create "agentic" app experiences.

**Current Projects & Focus:**
* **Full-Stack Engineering:** Leveraging the MERN stack to build tools like **Hive** (a real-time collaborative code editor using WebSockets/Yjs) and **KGP-Bazaar** (a campus marketplace featuring secure, QR-code-based handover mechanisms).
* **Mobile Transition:** Bringing complex, web-level functionality to cross-platform mobile environments.
* **AI & Gen AI:** Moving beyond standard CRUD architectures by integrating intelligent chatbots, prompt engineering, and supervised learning workflows.
